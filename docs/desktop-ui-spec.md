# 桌面端界面规范 v1

主窗口和首次引导都照这份规范写。控件的样式在 `src/renderer/shared/window.css`，尺寸、字号、圆角、动效的 token 在 `src/renderer/shared/tokens.css`，颜色只从主题来（`src/themes`）。悬浮条有自己的形状，不套这份规范。

规范由测试守着，能用命令查的才算数：

| 门禁 | 测试 | 查什么 |
| --- | --- | --- |
| 文案词表 | `test/i18n/copy-lexicon.test.mjs` | 中文词条里出现"不再使用"的说法就失败（命令行 `cli.*` 暂不在内） |
| 尺寸 token | `test/renderer/shared/control-sizes.test.mjs` | 控件的高度只用 `--control-*`，圆角只用 `--radius-*`，例外写明缘由 |
| 字号字重 | `test/renderer/shared/type-scale.test.mjs` | 字号只用七档、字重只用四档 |
| 颜色 | `test/themes/css-tokens.test.mjs` | 样式里不写死颜色，用到的变量都有出处 |

## 1. 文案

- **书面语**：不用口语（能用、用这个、填、挑、只看、交给、一步）。
- **不写整句**：按钮是动词或动宾，状态是名词或形容词短语，说明是名词短语，多项用" · "隔开，不带句末标点。
- **长度**：按钮、状态 2–4 个字；说明不超过 16 个字；口径、出处放进悬停提示。
- **数值**：数和单位之间空一格（0.9 秒、850 MB）；币种紧贴数字（¥0.8）；同一列的小数位一致。
- **提示**：操作结果写成"已 + 动词"（已启用、已切换至、密钥已保存）；失败写清对象和原因。

| 场景 | 规范写法 | 不再使用 |
| --- | --- | --- |
| 按钮 | 启用 · 检测 · 下载 · 配置密钥 · 更换 · 保存 · 取消 | 使用 · 用这个 · 检查 · 填 X Key |
| 状态 | 使用中 · 已选定 · 检测通过 · 检测失败 · 检测中 · 未配置 | 能用 · 不能用 · 已选 · 已填 · 未填 |
| 标题 | 识别方式 · 模型库 · 渠道 · 密钥 | 用法 · 挑模型 · 经由 · Key |
| 标签 | 默认 · 已评测 · 已知问题 · 未验证 | 实测 · 未实测 · 适合 Apple 芯片 |
| 筛选 | 仅显示可用 | 只看能用的 |
| 提示 | 已切换至转写 + 润色 · 密钥已保存 · 新增 22 个可用模型 | 已切到 · 解锁 22 个模型 |

标签只按事实打：跑过成批真实录音评测的打"已评测"，有已知问题的打"已知问题"（悬停看是什么），出厂默认的打"默认"。只跑通、没评测的不打标签；跑不通的不上架。照官方文档接入、还没拿真 key 调过的打"未验证"，跟着渠道走（同一个模型换一家卖可能就验过了），调通后摘掉。

## 2. 尺寸

- **控件高度三档**：`--control-sm` 28（胶囊、徽标、分段里的项）· `--control-md` 32（按钮、输入框、分段控件）· `--control-lg` 40（搜索框、分类标签）。同一行的控件同一档，字的长短不会把它们撑得参差。
- **圆角四档**：`--radius-control` 8（控件）· `--radius-block` 12（区块）· `--radius-card` 16（卡片）· `--radius-full`（胶囊）。
- **字号七档、字重四档**：见 `tokens.css`。
- **定宽列**：列表的状态列、操作列各 6rem（`--col-status`、`--col-action`），控件撑满列宽。

## 3. 按钮

- 四种：主要（`.button.primary`，主题色渐变）· 次要（`.button`，实底描边，默认）· 幽灵（`.button.ghost`，取消、收起）· 小号（`.button.small`，28 高）。撑满所在格子加 `.block`。
- 主要按钮每个区域至多一个，用于保存、确认；列表行内一律用次要按钮。
- 按钮必须有底色或描边，不拿纯文字当按钮（链接除外）。
- `window.css` 先用 `:where(button)` 去掉浏览器自带的按钮外观：哪个按钮的样式漏了，退回的是一段平的字，不会冒出灰色的系统按钮（有测试守着）。
- 不可点的状态（使用中、已选定）用状态框 `.state-box`，和按钮同高同圆角、占同一个位置。
- 不可用的按钮置灰保留，悬停说明原因，不隐藏。

## 4. 状态与检测

- 一套检测，模型、密钥两处共用，顺序固定：检测（`.check`）→ 检测中 → 检测通过 / 检测失败（`.badge`）。
- 结论用徽标：图标加淡底同色字，撑满状态列；通过只写结论，不附原文、耗时。结果徽标本身是按钮，悬停显示"重新检测"。
- 原因用说明框 `.callout`：在那一行下面，粗体结论加对象和原因，原始报错用等宽字。
- 标签 `.tag` 只有几种语气：默认（`accent`）· 已评测（`ok`）· 已知问题（`problem`）· 未验证（不加语气，灰底）；做法标签（Metal 版、CPU 版）用描边（`outline`）。

## 5. 选择控件

- **分类标签** `.tabs` / `.tab`：页面内分区；选中项下面一条主题色下划线滑过去，图标变主题色，计数在右边的小胶囊里。
- **分段控件** `.segmented` / `.segment`：二到四个互斥的选项（比如渠道），选中项是实底滑块；只有一个选项时外形不变、不能点。
- **筛选胶囊** `.pill`：几个并列的筛选项，选中的反白。
- **开关** `.toggle` 加 `.switch`：布尔设置，文字在左，用正文色。
- **单选卡片**：二选一的大选项，整张卡可点，选中的描主题色边，左上角实心圆加对勾（`.radio-mark`）。
- **浮层选单**：一个全局的选择（首页的识别方式）放在页面标题右边的胶囊按钮里，点开是锚在按钮下面的玻璃浮层（原生 `popover`，点外面、按 Esc 收起）。每一项写清它是什么、正在用什么、还差什么；差的东西旁边给"前往配置"，跳到负责它的那一页，不在浮层里改。

## 6. 列表

- 每张表都有表头；每行格数相同，空格也占位（`.table`、`.row`、`.row-head`）。
- 列：名称（自适应）· 数据列（定宽、右对齐、等宽数字）· 状态（6rem）· 操作（6rem）。同一页同类的表用同一套列宽。
- 状态列、操作列各放一个控件并撑满列宽，各行左右边缘一致。
- 缺前置条件（没配密钥、没下载）时，表头下面一行说明加一个按钮；行内的操作置灰保留。
- 同一列里最好的数标绿，不另写"快""小"这类标签。
- 宽度不够时，先把状态收成图标，再把数据列挪到名称下一行；不截断文字。
