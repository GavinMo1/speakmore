SpeakMore 的 README 以英文版（README.md）为主页，中文版（README.zh-CN.md）作为切换；两份内容同步改。用 HTML 排版、配轻量 emoji，语言简单干练，不写成论文或报告：讲清特色和怎么做的就行，细节收进折叠块，开发和验证记录放 docs/development.md。

**Why:** 2026-10-14 他说"现在要开始好好包装一下了"，最看重成本对比（Typeless 订阅一年约 $144，SpeakMore 用 Gemini 一个月几块钱）、准确率不输 Typeless、数据不经第三方。

**How to apply:** 改 README 时两份一起改；成本、准确率这类数字要有出处（官网价、真实用量估算），对外说法照实写，比如"程序在本机、录音直接发给模型厂商"，不要写成"本地识别"。相关：[[desktop-copy-and-look]]、[[speakmore-release-on-cos]]
