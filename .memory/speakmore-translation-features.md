2026-10-22 发完 0.15.0 后他提的两个功能。他的判断：内核几乎全复用，难的是“壳”，名字和板块不能乱。顺序是先理清产品形态、画清原型，再开发。

**10-22 他在选项里定了四件（都是我推荐的）：**
1. **结构**：功能 = 热键动作（`src/hotkeys/actions.mjs` 的动作目录）。引擎按入口分两段：
   - 语音：现在这棵树，语音输入和翻译输入共用。原生方式让模型直接出目标语言；转写方式的第二跳换提示词。“润色”这个环节名要换成中性的词，我提的是“成稿”，还没定。
   - 文字：给划词翻译用，单选一个文字模型。后来又定了和语音完全分开，见下。
2. **名字**：当时定的是语音输入、翻译输入、划词翻译，后来“翻译输入”改成了“语音翻译”（见下）。
3. **划词只用热键触发**：不做“选中就冒图标”。
4. **数据隐私方式第一版不提供翻译**：本机的 Qwen3-ASR、SenseVoice 只能转写，那条路上也没有文字模型。界面写明原因，留缝以后接本机文字模型。

**10-22 又定了（选项里选的）：**
- 名字改成：语音输入、语音翻译、划词翻译。
  - 之前用的“翻译输入”作废。
  - “同声传译”不用：同传是边听边译、出的是口头译文；我们是说完才出文字，懂行的人会挑。
  - 想要鲜明就靠宣传语，比如“说中文，出英文”。
- 设置按功能分栏：
  - 通用：界面语言、主题、开机启动、存储位置、软件更新
  - 快捷键：四个动作、悬浮条按键提示
  - 语音翻译：译成，可多个，一行一种，第一行是默认
  - 划词翻译：只有“译成”一项。他要两个翻译各配各的目标语言，内核里只是提示词、策略不同。
    - “选中的已是这种语言时”他看不懂，删掉，交给内核。
    - 卡片位置不出设置，定一种写死。
  - 本机模型：下载源、加速、空闲释放
  - 权限、关于
  - 不再设“母语、常用外语”这种两个功能共用的概念。
- 他要整个 App 的文案讲人话，“转写 + 润色”“原生”这些用户看不懂。
  - 识别方式的叫法见 [[speakmore-two-pipelines]] 10-22 那条：不按过程、不带优劣，要直观的短名。

**10-22 再定：**
- 默认键：
  - 语音输入：右⌥（Windows 是右 Alt）
  - 语音翻译：右⌥ + 空格（Windows 是右 Alt + 空格）
  - 划词翻译：右⌥ + 回车（Windows 是右 Alt + 回车）
  - 他嫌右⌥ + 右⇧、右⌥ + T“稀奇古怪”。
- 做的时候要改热键规则（`src/hotkeys/validate.mjs`、`keys.mjs`，`docs/hotkey-research.md` 一起改）：
  - Windows 的 `winAltSpace` 现在左右 Alt + 空格都拦，改成只拦左边。右 Alt + 空格被吞后窗口菜单还弹不弹，没验证，要在他那台 Windows 上实测。
  - `Enter` 在键表里是 blocked，连带修饰键都不让绑。改成 typing，修饰键加回车就能绑。
    - ⇧、⌘、⌃、fn 加回车，现有规则照样会拦。
    - 另拦 Windows 的左 Alt + 回车：表格里是单元格换行。
- **划词的模型和语音的完全分开**：引擎页“划词”那一段只有厂商、型号两列，自己选一个，出厂 DeepSeek V4.1 Flash。不出现“同语音的整理模型”这种关联。
  - 他的原话：检查、密钥这些内核机制共用，只是适配器里放的提示词不同，“不能让用户有任何感觉”。

**10-22 收尾定的：**
- 划词卡片放选区下方，不出设置。
- 悬浮条上临时换的语言只管这一次，下次回到设置里的默认。
- 划词翻译进历史。
- 老用户不专门提示：做出来以后改 README、官网，发宣传片。
- 已定的：划词结果弹卡片不贴字；卡片上“复制”，选区可编辑时多“替换选中文字”；语音翻译进历史，原文译文都存；首页口述统计不算划词；花费都记。

**参照**：
- Typeless 的翻译是第三个热键（Fn + 左 Shift，Windows 是右 Alt + 右 Shift），和听写共用悬浮条和后端，只多一个 `output_language`（`targets/typeless/docs/04-voice-pipeline.md:99`）。目标语言在悬浮条上悬停切换，2.0 起能预存几个。
- Typeless 没有划词翻译。Easydict 有选中冒图标和 ⌥D 两种。

**没验证**：原生方式那几个收音频的模型能不能纯文字进出。
