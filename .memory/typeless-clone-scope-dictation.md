用户 2026-10-13 的原话大意：平常用 Typeless 主要就是语音转写——按一次 fn，说话，结束后再按一次，转写结果落到选中的地方，也会存进 app 的历史记录。他没有提翻译模式和"问任何事"。

**Why:** 逆向 Typeless 的目的是学习，之后仿刻一个服务端自建的玩具。这是他描述的实际使用面。

**How to apply:** 讨论仿刻（任务第四步）时，默认把"单击听写 → 插入到焦点输入框 → 存历史"当核心范围；翻译、问任何事、云同步要不要做先问他，不默认带上。"核心范围"是我的理解，他没有明说砍掉其他功能。抓包和文档的重点也按这个排：听写场景必做，其他模式列为可选。相关：[[rea-is-the-primary-tool]]。
